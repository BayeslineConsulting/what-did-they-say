## Methodology
Lead: census-based qualitative content analysis of one conference; inductive coding by one coder against a written protocol; every excerpt in the action list and example tables machine-verified. Reporting follows SRQR (O'Brien et al., 2014).

### Coding procedure
First cycle (Initial / In Vivo / Process; new-code rule; hybrid master codebook — reuse first, new codes logged; memo per talk). Action items (pattern search + full reading; inclusion rules). Scripture and word metrics (identification method; spoken-citation rate; reconciliation status).
