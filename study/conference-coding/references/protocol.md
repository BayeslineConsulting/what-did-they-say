# Coding protocol (series standard)

Adapted from Saldaña, *The Coding Manual for Qualitative Researchers*, and Williams & Moser (2019).

## Units
- Unit = one transcript paragraph inside an address (a meaning unit). Short continuation lines (<25 characters) attach to the preceding unit.
- Excluded: sustainings, conducting remarks, prayers, music.
- Each unit gets 1–3 codes. Rhetorical codes (category C26) count toward the 3.

## First cycle
- **Initial** coding by default: a short noun phrase for what the unit is an instance of.
- **In Vivo** when the speaker's words carry the concept; keep in quotes (`"no asterisk"`).
- **Process** coding with gerunds for actions (seeing the individual, inviting divine help).
- Lowercase, ≤4 words, identical wording across talks and conferences.

## Hybrid master codebook
1. Search the master first. If an existing definition covers the unit, use it (widen the definition only with a logged rationale).
2. Add a new code only if you can write a one-sentence definition plus include and exclude rules a second coder could apply. Put it in `new_codes.json` with a key of 3 capital letters not already used.
3. New categories need ≥2 codes and ≥3 units across ≥2 talks; otherwise attach the code to the closest existing category.
4. Never rename or delete master codes. Retire by status: codes unused in a run show as "dormant"; propose merges in the Codebook_Log, applied only with the user's agreement.
5. Status rules (computed in the workbook): new this run · active (≥2 talks) · talk-specific (1 talk, ≥3 units) · provisional (1 talk, ≤2 units) · dormant.

## Distinguish loss stories and rhetoric
- Loss stories → `personal loss narrative` (not also `personal narrative`).
- `cross-talk reference` only for explicit references to another talk the same weekend.

## Second cycle
- Axial: categories are hubs, codes spokes; ask causes, contexts, consequences.
- Selective: themes are claims ("Speakers corrected a prosperity reading of obedience…"), each mapped to categories. Default 10 themes for the series.
- Report breadth (talks with ≥1 unit) and depth (distinct units) per theme, plus session spread.

## Memos
One per talk, written right after coding it: turning point, code hesitations, what this talk has that others lack.

## Reliability
Single coder. The workbook's Reliability sheet holds one talk for blind double-coding at the primary-theme level (% agreement, Cohen's κ; κ < 0.61 → tighten theme definitions).
